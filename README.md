## Спринт 3

Добавлен формат цепочки версии 2 с `record_hash` у каждой записи, детальная локализация ошибок валидации и сверка внешнего JSON-файла с `document_hash`. Импорт версии 1 намеренно отклоняется: записи старого формата не имеют отдельного хэша содержимого. Перед загрузкой изменений в Git прогон тестов не выполнялся; тестировщик должен выполнить команды из `README_QA.md`.

Локальные SHA-256-хэши обнаруживают несогласованное изменение данных. Без цифровых подписей или внешней доверенной контрольной точки они не защищают от согласованного переписывания головы цепочки; подробности — в требованиях CORE-11–CORE-13.
