# QA-отчёт — спринт 3

## Объект и цель
Проект: реестр медицинских рецептов на блокчейне. Проверяются требования CORE-11 (хэш записи), CORE-12 (валидация и локализация ошибки), CORE-13 (проверка внешнего JSON-файла), а также связанные сценарии импорта и версий схемы.

## Подготовленные тесты
Файл: `tests/test_sprint3.py`. 19 именованных сценариев, 28 проверок с учётом параметризации. Проверяются корректная цепочка, независимый расчёт SHA-256, создание хэша записи, подмена трёх полей записи с пересчётом хэша блока, порча хэша записи, подмена метки времени, нарушение ссылки на предыдущий блок, неправильный индекс, повреждённый genesis, пустая цепочка, первая ошибка в нескольких блоках, отказ в импорте изменённой записи, совпадение хэша внешнего документа, изменение/добавление/удаление полей документа, перестановка ключей JSON, некорректный JSON (4 варианта), отсутствие файла, неизвестный ID и отказ в импорте старой схемы.

## Запуск
```bash
python -m pip install -r requirements.txt
python -m pip install pytest
python -m pytest tests/test_sprint3.py -v
python -m pytest tests/ -v
```

## Статус
Тесты подготовлены, синтаксис Python проверен. Полный прогон **не выполнен** в среде подготовки: отсутствует зависимость `rfc8785==0.1.4`, а установка из сети недоступна. **Не указывать PASS/FAIL до запуска в GitHub Codespaces.** После запуска вставить фактические результаты и описать дефекты с шагами воспроизведения.

## Граница безопасности
Локальные хэши обнаруживают несогласованную подмену. Полное переписывание цепочки с пересчётом всех хэшей без внешней доверенной контрольной точки не гарантированно обнаруживается — это явно вне объёма спринта 3.
