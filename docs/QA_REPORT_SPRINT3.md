# QA-отчёт — спринт 3

## Объект и цель

Проект: реестр медицинских рецептов на блокчейне.

Цель тестирования — проверить целостность блокчейна, обнаружение несанкционированных изменений данных, корректность вычисления хэшей, определение места ошибки и проверку внешних документов.

Тестирование выполнено в соответствии с требованиями третьего спринта:

- **CORE-11** — проверка целостности хэшей блоков и записей.
- **CORE-12** — валидация цепочки и локализация ошибок.
- **CORE-13** — проверка целостности внешнего файла.

## Подготовленные тесты

Файл: `tests/test_sprint3.py`.

Разработаны автоматизированные тесты на Python с использованием библиотеки pytest.

Проверены следующие сценарии:

1. Проверка корректной цепочки блоков.
2. Проверка правильности вычисления SHA-256.
3. Обнаружение изменения содержимого записи.
4. Обнаружение подмены хэша записи.
5. Обнаружение изменения хэша блока.
6. Обнаружение изменения временной метки блока.
7. Обнаружение нарушения связи с предыдущим блоком.
8. Обнаружение неправильного индекса блока.
9. Проверка целостности генезис-блока.
10. Обработка пустой цепочки.
11. Определение первой ошибки в цепочке из нескольких блоков.
12. Проверка сохранения хэшей при импорте данных.
13. Проверка корректного внешнего документа.
14. Обнаружение изменения, добавления и удаления данных внешнего документа.
15. Проверка независимости хэша от порядка ключей JSON.
16. Обработка некорректного JSON.
17. Обработка отсутствующего внешнего файла.
18. Обработка неизвестной записи.
19. Отклонение импорта данных со старой версией схемы.

## Запуск тестирования

Тестирование выполнено в GitHub Codespaces в ветке `main`.

Для запуска использована команда:

```bash
python -m pytest tests/test_sprint3.py -v
```

## Граница безопасности

Реализованные проверки позволяют обнаруживать изменения данных, нарушающие целостность блоков, записей и связей между ними.
