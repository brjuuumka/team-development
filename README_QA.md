# Инструкция QA — спринт 3

## Область

Проверки T-01–T-18 из [`docs/test-plan.md`](docs/test-plan.md). Основной результат для новых требований — локализованное обнаружение изменения записи, включая случай пересчитанного хэша блока, и проверка содержимого внешнего JSON-файла.

## Запуск

Из корня репозитория установите зависимость и запустите автотесты:

```sh
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

На Windows можно использовать `py` вместо `python`. Зафиксируйте версию Python и `rfc8785`, итоговое число пройденных/непройденных тестов и текст ошибок. Не меняйте ожидаемый результат теста только для совпадения с реализацией: сначала зарегистрируйте расхождение.

## Ожидаемый интерфейс

`validate_chain()` возвращает словарь с `valid`, `error_block_index`, `error_record_id`, `reason`. `verify_external_document(path, record_id)` возвращает `True` или `False` и не выбрасывает исключение для невалидного/отсутствующего файла.

## Статус

Автоматический прогон после изменений спринта 3 не выполнялся. Тесты подготовлены для независимого запуска тестировщиком.
