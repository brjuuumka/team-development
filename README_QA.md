# QA — спринт 2

Автотесты `tests/test_core.py` соответствуют T-01–T-12 из `docs/test-plan.md`. T-13 относится к будущему сервису документов и не включён.

## Запуск (Windows, из корня репозитория)

```powershell
py -m pip install rfc8785
py -m unittest discover -s tests -v
```

При отсутствии команды `py` используйте `python`.

- `OK` — тесты прошли.
- `FAIL` — поведение не соответствует ожидаемому.
- `ERROR` — исключение или отсутствующий метод; необходимо изучить причину.

Намеренно **не исправляйте тесты под ошибочную реализацию**: сообщите о расхождении разработчику. Тесты не изменяют `src/core.py`; временные файлы создаются в системной временной папке.

## Особенности

- T-05: при нарушении ссылки на предыдущий блок пересчитывается собственный хэш изменённого блока, чтобы изолировать проверку `PREVIOUS_HASH_MISMATCH`.
- T-06: хэш изменённого genesis также пересчитывается, чтобы проверить именно инвариант genesis.
- T-12: экспорт — это файл JSON; изменение считанного из него словаря не должно менять цепочку в памяти.
- T-10 предполагает метод `get_prescription_history`; если разработчики выбрали другое имя, согласуйте интерфейс с аналитиком и адаптируйте вызов, а не объявляйте дефект без уточнения.
